# Rohit Maruri — Personal Website

Static personal website for Rohit Maruri, built with HTML, CSS, and vanilla JavaScript.

## Local preview

Run any static server from this directory, for example:

```bash
python -m http.server 4173
```

The site includes a live GitHub contribution graph, project links, research, writing, and responsive layouts.

Deployment is handled by `.github/workflows/deploy-pages.yml`.
